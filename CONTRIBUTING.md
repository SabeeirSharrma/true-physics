# Contributing to True Physics

Thank you for your interest in **True Physics**!

To ensure the project's performance targets, architecture, and code quality remain tightly aligned, **True Physics operates under a strict "No Unsolicited Pull Requests" policy.**

Please read these guidelines carefully before opening an issue or attempting to contribute.

---

## Pull Request & Direct Commit Policy

> **Main Repository Policy:** Direct commits to the main repository are restricted, and unsolicited Pull Requests (PRs) will be closed without review.

### Why this policy exists

* **Architectural Integrity:** Physics engines in Minecraft interact heavily with rendering pipelines, chunk management, and server-side tick logic. Uncoordinated changes can introduce subtle bugs or severe performance drops.
* **Maintainer Overhead:** Reviewing unannounced code takes considerable time away from active development.

### How to get approval for a PR

1. **Open an Issue first** describing the bug fix, optimization, or feature you wish to address.
2. Wait for a core maintainer to review the proposal and explicitly assign or tag the issue with `approved-for-pr` or `help-wanted`.
3. Only submit a PR **after** receiving explicit confirmation from a maintainer.
4. Ensure your PR references the original issue number.

---

## Reporting Bugs

Bug reports are always welcome and help make True Physics better for everyone.

### Before submitting

* **Search existing issues** to avoid creating duplicates.
* Verify you are using the latest version of True Physics and its required dependencies.

### What to include in your issue

**Please follow the provided issue templates**

* **Mod Version:** Exact build version (e.g., `True Physics 1.2.0`).
* **Minecraft & Loader:** Loader and version (e.g., Minecraft `26.2`, Fabric  / NeoForge version).
* **Mod List:** Mention any rendering/performance mods installed (e.g., Sodium, Iris, Embeddium, Lithium).
* **Reproduction Steps:** Detailed steps to reliably trigger the issue.
* **Logs:** Attach or link crash logs/latest logs via a paste service (e.g., Pastebin or GitHub Gist). Do not paste massive raw logs into the issue body.

---

## Feature Requests & Feedback

If you have ideas for new physics features, tweakable options, or performance enhancements:

1. Search open and closed issues/discussions to see if the topic has already been covered.
2. Open a new issue framing your idea as a **Feature Request**.
3. Focus on **what** the feature adds, **why** it improves gameplay/realism, and any potential performance considerations.

---

## Community Guidelines

Please keep all interactions in issues, pull requests, and discussions civil, respectful, and constructive.
